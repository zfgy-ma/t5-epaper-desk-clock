# T5-2.13 墨水屏背板

LILYGO T5 2.13 英寸墨水屏开发板的配套装饰背板，采用 PCB 工艺制作，用于
遮挡主板背面元件，让桌面时钟摆放时外观更整洁。

背板为纯装饰结构（无电路走线）：四角 R2 圆角，板面丝印花徽图案、
"T5-2.13" 与 "墨水屏背板" 字样及波浪装饰带；四角 Ø2.0mm 金属化
安装孔与原板孔位一致，使用 M2 螺丝固定。

## 规格

| 项目 | 参数 |
| --- | --- |
| 外形尺寸 | 36.75 × 66.29 mm |
| 圆角 | 四角 R2 mm |
| 安装孔 | Ø2.0 mm 金属化通孔 ×4 |
| 孔距（水平 × 垂直） | 32.36 × 61.43 mm |
| 孔中心到边 | 左 2.15 / 右 2.25 / 上 2.52 / 下 2.35 mm |

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `T5-2.13-背板-EDA工程/` | 立创EDA 专业版工程源文件，用[嘉立创EDA专业版](https://pro.lceda.cn/)打开其中的 `T5-2.13-背板.eprj3` 即可继续编辑 |
| `T5-2.13-背板-Gerber.zip` | 打板文件（Gerber 各层 + 钻孔数据），可直接上传嘉立创下单 |

## 打板说明

- 板厚、阻焊颜色、表面处理按下单需求自选（3D 预览中的黑底白字效果可供参考）
- Gerber 包内为毫米单位、4:5 数字格式，含金属化钻孔文件与钻孔表
